# Pawth Landing Page

日々の記録と振り返りを支援するアプリ「Pawth」の紹介用ランディングページです。

UI・UXや品質改善、Web開発の技術検証を目的に制作しています。

## Live Demo

🌐 [Webサイトを見る](https://pawth-lp.hamltail.dev/)

Alternative: [Vercel Deployment](https://pawth-lp.vercel.app/)

## Tech Stack

| Category       | Technologies                                             |
| -------------- | -------------------------------------------------------- |
| Design         | Krita                                                    |
| Frontend       | TypeScript, React, Next.js, Tailwind CSS, next-intl      |
| Testing        | Vitest, Playwright, Stryker, axe-core, Lighthouse CI, k6 |
| Security       | OWASP ZAP, CodeQL                                        |
| Infrastructure | Docker, Vercel, GitHub Actions                           |

## Technical Decisions

当初は HTML・CSS・JavaScript による静的サイトとして制作していましたが、機能拡張や継続的な改善を行いやすくするため、Next.js へ移行しました。

アクセシビリティやE2Eテストなどを取り入れ、実装後も継続的に品質を確認・改善できる構成にしています。

## Development

- **開発期間：** 2026年6月〜10月（以降も継続改善）
- **ソースコード公開期間：** 2026年6月〜10月

2026年6月にHTML・CSS・JavaScriptを用いて制作を開始し、アニメーションやアプリ画面の紹介機能を実装した後、7月にNext.jsへ移行しました。

その後、Tailwind CSSの導入、UI・UX、アクセシビリティ、テスト、セキュリティなどの改善を継続しています。

ソースコードは2026年6月から10月までGitHub上で公開していましたが、現在は非公開としています。

本リポジトリでは、制作実績としてプロジェクトの概要および技術構成を公開しています。
